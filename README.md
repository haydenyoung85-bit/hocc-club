# Heart of Oklahoma Corvette Club website

Live site: https://haydenyoung85-bit.github.io/hocc-club/ (will move to https://hocc.club once DNS is pointed here).
Admin panel: `/admin/` (email + password).

## How it works
- Plain HTML pages + `style.css` + `site.js`. No build step, no server, free GitHub Pages hosting.
- **All content lives in `content/site.json`.** `site.js` reads it and fills in every page.
- The admin panel (`admin/`) edits `content/site.json` and uploads photos to `images/uploads/` by saving to this GitHub repository with the GitHub API. GitHub Pages republishes in about a minute.
- Admin login: `admin/login.json` holds a GitHub token for this repository, encrypted (AES-GCM, PBKDF2-SHA256 600k) with each editor's password. Editors can change their password and add/remove editors from the admin "Password & editors" screen.
- Show registration is built but switched OFF (`registration.enabled=false`). When ON, it appears on the Car Show page on the opening date. Forms (membership, contact, for-sale submissions, registration) are emailed to the club through FormSubmit.co; payments use the club's PayPal links.

## Maintainer tasks
- Turn on / re-key the admin: create a GitHub fine-grained token with access to ONLY this repository and "Contents: Read and write", then
  `node tools/make-login.mjs --email hoccclub@gmail.com --password-file pw.txt --token-file token.txt --out admin/login.json` and commit `admin/login.json`.
- Page shells are generated by `python3 tools/build-pages.py` (edit that file to change page layout; it adds new heading keys to `content/site.json` under `text` without overwriting edits).
- Custom domain: add a `CNAME` file containing `hocc.club` (or set it in repo Settings → Pages) and point DNS at GitHub Pages.
